# 32 · Product Usage by Tier or Plan

> **Part:** [[D - Product & Engagement]]  ·  **Index:** [[How to Analyze a SaaS Company]]

## 🎯 Goal
The goal of the Product Usage by Tier or Plan analysis is to evaluate how users across different pricing tiers or subscription plans engage with a SaaS product. This analysis helps a SaaS company understand how features are being utilized at different pricing levels, identify opportunities for upselling or cross-selling, and assess whether higher-tier plans are delivering sufficient value to justify their price.


## 📊 Data required
1. **Number of users by tier or plan:** Total number of users subscribed to each pricing tier (e.g., Basic, Pro, Enterprise).
2. **Product usage data per tier:** Metrics on how users within each tier are engaging with product features (e.g., number of sessions, feature usage, or time spent).
3. **Feature availability by tier:** A list of features available in each pricing tier to compare feature utilization against access.
4. **Revenue per tier:** Total revenue generated by each tier, if relevant to assess revenue contribution versus usage.


## 🪜 Step-by-step
1. Segment users by pricing tier or plan:
o    Group users based on their subscription tier (e.g., Basic, Pro, Enterprise). Ensure that each tier's users are clearly deﬁned and that the features available to each group are well understood.
2. Calculate the number of active users per tier:
o    Count the total number of users actively using the product in each tier within a speciﬁc time period (e.g., monthly or quarterly). This provides a baseline for comparing usage across tiers.
3. Track product usage metrics for each tier:
o    For each tier, track key usage metrics such as:
   Usage Frequency: The number of sessions per user in a given period.
   Feature Usage: The percentage of available features used by each tier.
   Time Spent: The average time users spend in the product per session.

`o    Use the formula for each tier: Feature Usage by Tier (%) = (Number of Features Used by Tier / Number of Available Features in Tier) x 100`
o    For example, if users in the Pro plan have access to 15 features and on average use
`10: Feature Usage by Tier = (10 / 15) x 100 = 66.67%`
4. Compare usage metrics across tiers:
o    Analyze the differences in product usage between tiers. For example, compare the average sessions per user in the Basic tier versus the Pro tier to see if higher-paying customers are engaging more deeply with the product.
5. Evaluate feature utilization by tier:
o    Assess how much of each tier’s available features are being utilized. Users in higher tiers should ideally be taking advantage of premium features to justify the additional cost of their plan.
o    For each tier, analyze the percentage of users who engage with speciﬁc premium features to understand if the higher-value offerings are delivering perceived value.
6. Assess revenue contribution by tier (optional):
o    To understand the business impact, compare the total revenue generated by each tier to its respective usage. This helps determine if certain tiers are over- or underutilized relative to their cost.

## 🔍 How to interpret the results
•   High usage in premium tiers: If users in higher-priced tiers (e.g., Pro or Enterprise) show higher feature usage and engagement, this indicates that they are extracting signiﬁcant value from the product, justifying the cost of the higher tier. These users are likely to renew their subscriptions and represent potential upsell opportunities.
•   Low usage in premium tiers: If feature usage or engagement is low in higher tiers, it may indicate that premium features are not being effectively utilized or that the product isn’t delivering enough value to justify the higher price. This can signal a need to improve feature adoption or revisit the pricing model.
•   High usage in lower tiers: If users in lower-priced tiers (e.g., Basic) are heavily engaging with the product but not upgrading, it suggests potential upsell opportunities. Offering feature trials or limited-time discounts on higher-tier plans may encourage them to upgrade.
•   Low usage in lower tiers: Low engagement in the Basic tier may indicate that users are not ﬁnding enough value in the product to become more active. This could lead to higher churn rates unless addressed through onboarding improvements or educational efforts to showcase more value.


## 🚀 Steps to improve
1. **Improve feature education:** Provide targeted in-app guides or tutorials that highlight premium features and show users how to unlock additional value from their current plan. This can increase feature usage and potentially encourage upgrades to higher tiers.

2. **Enhance feature diKerentiation by tier:** Ensure that each tier offers a clear and compelling difference in value. If users in higher tiers are not utilizing premium features, consider bundling more advanced capabilities into the higher-priced plans or offering exclusive features that drive deeper engagement.
3. **Run upsell campaigns:** For users in lower tiers who are heavily engaging with the product, run targeted upsell campaigns that promote the beneﬁts of upgrading to a higher-tier plan. Offering a free trial or limited-time discount on premium plans can incentivize users to move up.
4. **Monitor underutilized features:** For features that are underutilized across tiers, investigate potential reasons (e.g., lack of awareness, complexity) and address those issues. Simplify workﬂows, improve feature discoverability, or provide more educational content to increase usage.
5. **Optimize pricing strategies:** If usage is concentrated in certain tiers without proportional revenue growth, consider adjusting pricing or adding more ﬂexible plan options to capture value from users who are actively engaged but not upgrading.
6. **Personalize engagement based on tier:** Tailor customer success and support efforts based on tier. Higher-tier customers should receive more proactive support to ensure they are using premium features, while lower-tier users can beneﬁt from regular check-ins and product tips to increase engagement.
