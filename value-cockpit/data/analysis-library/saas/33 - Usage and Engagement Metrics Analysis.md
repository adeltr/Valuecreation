# 33 · Usage and Engagement Metrics Analysis

> **Part:** [[D - Product & Engagement]]  ·  **Index:** [[How to Analyze a SaaS Company]]

## 🎯 Goal
The goal of Usage and Engagement Metrics analysis is to measure how often and how deeply customers are using a SaaS product. This analysis helps SaaS companies understand customer behavior, identify power users, detect signs of disengagement or churn risk, and assess how well the product is meeting customer needs. Higher usage and engagement are often correlated with better customer retention and satisfaction.


## 📊 Data required
1. Number of active users (daily, weekly, or monthly)
2. Number of logins or sessions per user
3. Key product feature usage frequency (e.g., how often users access core features)
4. Duration of each session
5. Number of actions performed during each session (e.g., number of tasks completed, messages sent)
6. User segmentation (optional) to analyze behavior across different customer segments


## 🪜 Step-by-step
1. **Deﬁne the key engagement metrics:** Decide which metrics are most relevant to your product’s value. Common metrics include:
o    Daily Active Users (DAU): The number of unique users who engage with the product each day.
o    Monthly Active Users (MAU): The number of unique users who engage with the product over a month.
o    Session frequency: How often users log into the product.
o    Session duration: The average time spent per session.
o    Feature usage: How often key features (e.g., reporting, collaboration tools) are used.
2. **Collect data on user activity:** Use your analytics platform (e.g., Google Analytics, Mixpanel, or in-app event tracking) to gather data on user activity for the chosen period (daily, weekly, or monthly). This includes:
o    Number of logins per user 106 o    Time spent in each session o    Number of actions or tasks completed o    Frequency of key feature usage
3. **Calculate DAU/MAU ratio:** The DAU/MAU ratio measures how "sticky" the product is by showing the proportion of users who engage with the product daily. Use the following formula:
`DAU/MAU Ratio = (Daily Active Users / Monthly Active Users) x 100`
For example, if you have 1,000 DAU and 5,000 MAU, your DAU/MAU ratio is:
`DAU/MAU Ratio = (1,000 / 5,000) x 100 = 20%`
4. **Analyze session frequency and duration:** To assess user engagement, calculate the average number of sessions per user and the average session length. Use the following formulas:
`Average Sessions per User = Total Number of Sessions / Number of Active Users`
Average Session Duration = Total Time Spent by Users / Total Number of Sessions For example, if users had 10,000 sessions and spent 5,000 hours in the product, the average session duration is:
`Average Session Duration = 5,000 hours / 10,000 sessions = 0.5 hours (or 30 minutes)`
5. **Evaluate feature usage:** Identify how frequently users are interacting with the product's core features. This can provide insights into whether certain features drive engagement and value. For instance, track how often a reporting feature is used compared to other secondary features.
6. **Segment users by engagement level:** Group users into segments based on their engagement levels (e.g., high, moderate, and low engagement). For example, power users may log in daily and use advanced features, while low-engagement users might log in only once a month and use basic features.


## 📤 Output format
The output typically includes several key metrics such as:
•   DAU/MAU Ratio: A percentage that shows how frequently users engage with the product.
•   Average Sessions per User: The number of times users log in during a speciﬁc period.
•   Average Session Duration: The average length of time users spend during each session.
•   Feature Usage Frequency: How often speciﬁc features are used.
For example:

## 🔍 How to interpret the results
•   High DAU/MAU Ratio: A high ratio (e.g., above 20%) suggests that users are highly engaged with the product on a daily basis. This is a positive indicator of product stickiness.
•   Low DAU/MAU Ratio: A low ratio (e.g., below 10%) may indicate that users engage with the product infrequently, which could be a sign of disengagement or that users only ﬁnd value in the product occasionally.
•   Long session duration: If users are spending more time per session, it may indicate that they ﬁnd the product valuable or that certain features require extended interaction. However, excessively long sessions could suggest usability issues.
•   High feature usage: Frequent use of key features suggests that users are gaining value from the product and are more likely to remain engaged. If key features are underutilized, this may indicate a need for feature education or that certain features don’t meet user needs.


## 🚀 Steps to improve
1. **Increase product onboarding eKectiveness:** Provide better onboarding experiences that guide users through the most valuable features of the product. Educating users on how to maximize the product’s value can improve engagement.
2. **Implement user engagement campaigns:** Use email marketing, in-app notiﬁcations, and other outreach methods to encourage users to log in more frequently and explore additional features.
3. **Introduce product tutorials and resources:** Offer interactive tutorials or help resources to ensure users understand how to use key features effectively, boosting engagement.
4. **Analyze and enhance core features:** If certain features drive higher engagement, focus on improving or expanding these areas of the product. Likewise, if some features are underused, investigate why and adjust accordingly.
5. **Monitor and address churn risk:** Identify users with low engagement (e.g., low session frequency or duration) and reach out to them with personalized support or offers to prevent churn.
