# 15 · Return on Invested Capital (ROIC) by Generation Type

> **Part:** [[C - Financial and Market Strategy]]  ·  **Index:** [[How to Analyze an Electricity Generation Company]]

## 🎯 Goal
To assess the profitability and capital efficiency of different electricity generation types by calculating their Return on Invested Capital (ROIC). This analysis identifies which generation types deliver the highest returns relative to the capital invested, guiding strategic investment and divestment decisions.


## 📊 Data required
1. Operating income (EBIT) for each generation type.
2. Invested capital for each generation type (e.g., fixed assets, working capital, and other investments).
3. Depreciation and amortization data (optional for refining operating income).
4. Historical and forecasted performance data for revenue and costs.
5. Industry benchmarks for ROIC by generation type.


## 🪜 Step-by-step
1. **Calculate Operating Income (EBIT):** ○ Extract the revenue and operating costs for each generation type. ○ Use the formula:
`EBIT = Revenue - Operating Costs (including depreciation and amortization, if applicable).`
2. **Determine Invested Capital:** ○ Sum up the fixed assets (e.g., power plants, infrastructure) and working capital for each generation type:
`Invested Capital = Fixed Assets + Net Working Capital`
3. **Calculate ROIC:** ○ Use the formula:
`ROIC (%) = (EBIT / Invested Capital) x 100`
4. **Segment by Generation Type:** ○ Perform the calculation for each generation type (e.g., coal, natural gas, renewables, nuclear) separately to compare their performance.
5. **Evaluate Historical Trends:** ○ Analyze changes in ROIC over time to identify trends and potential impacts of market conditions or operational improvements.
6. **Compare to Benchmarks:** ○ Benchmark calculated ROIC values against industry averages for each generation type.

7. **Perform Sensitivity Analysis:** ○ Assess how variations in key factors (e.g., fuel costs, operational efficiency, or capital investment) affect ROIC for each generation type.


## 📤 Output format
1. A table summarizing EBIT, invested capital, and ROIC for each generation type.
2. A bar chart comparing ROIC across different generation types.
3. A trend graph showing historical changes in ROIC for each generation type.
4. Scenario models demonstrating the impact of key variables on ROIC.


## 🔍 How to interpret the results
1. High ROIC values indicate generation types that are efficiently converting capital into profits and are strong candidates for further investment.
2. Low ROIC values may signal inefficiencies, high capital costs, or operational issues.
3. Comparing ROIC across generation types and benchmarks can highlight competitive strengths or weaknesses in the portfolio.


## 🚀 Steps to improve
1. Optimize operational efficiency to reduce costs and improve EBIT.
2. Reallocate capital from low-performing generation types to higher-performing ones.
3. Invest in technologies or practices that enhance the profitability of underperforming assets.
4. Evaluate opportunities to divest from generation types with consistently low ROIC.
5. Improve revenue streams by exploring higher-margin market opportunities (e.g., renewable energy incentives or premium markets).
6. Conduct regular reviews of capital deployment strategies to ensure alignment with market trends and organizational goals.
